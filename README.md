# Vehicle Dynamics Simulation Project

The goal of this project is to investigate how well the simple 2-DOF bicycle model is able to predict real vehicle dynamics. This will be examined by taking data from driving a 2017 Toyota Camry and comparing it with a vehicle dynamics simulation built from the previously mentioned bicycle model. The deliverable will be a code repo, write-up, and validation plots that allow us to visually and quantitatively compare real driving to the built simulation.
